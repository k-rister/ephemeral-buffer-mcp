# Security Policy

## Supported versions

Security fixes are made against the latest version on the `main` branch and,
when practical, the latest published package release. Older releases may not
receive fixes.

## Reporting a vulnerability

Please do not report suspected vulnerabilities in a public issue. Send a
private report to `krister@redhat.com` with:

- a short description of the issue and its impact;
- affected versions, configuration, and operating system details;
- reproducible steps or a minimal proof of concept; and
- any suggested mitigation, if available.

Do not include credentials, captured user data, or other secrets unless they
are essential to demonstrate the issue. Redact them whenever possible.

You should receive an acknowledgement within seven days. We will work with
the reporter to understand the issue, determine affected versions, and
coordinate a fix and disclosure timeline.

## Privacy-sensitive reports

If a report concerns accidental exposure of captured command output or user
data rather than a security vulnerability, use the same private contact
channel and do not post the material publicly.
